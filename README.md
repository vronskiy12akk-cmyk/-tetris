# Тетрис (с физикой)

Многоязычная консольная реализация классической игры «Тетрис» с улучшенной физикой падения.  
Добавлены инерция, ускорение при падении, плавное движение и реалистичные столкновения.

## Особенности
- Стандартные фигуры (I, O, T, S, Z, J, L) с цветовой индикацией.
- Физика падения: ускорение со временем, инерция при боковом движении.
- Плавное вращение с проверкой коллизий.
- Заполнение рядов с анимацией исчезновения.
- Система уровней: скорость падения увеличивается с каждым уровнем.
- Подсчёт очков и рекорд (сохраняется в файл).
- Цветной вывод в терминале (ANSI-коды).
- Управление: `←/→` – движение, `↑` – вращение, `↓` – ускоренное падение, `Space` – мгновенное падение, `P` – пауза, `Q` – выход.
- Кроссплатформенность (Windows, Linux, macOS).

## Установка и запуск
Для каждого языка требуются соответствующие инструменты и зависимости (указаны ниже).

### Запуск на разных языках

1. **Python**  
   Установка: `pip install colorama keyboard` (или `pynput`).  
   Запуск: `python tetris.py`

2. **Rust**  
   Сборка: `cargo build --release`  
   Запуск: `cargo run --release`

3. **Go**  
   Запуск: `go run tetris.go`

4. **JavaScript (Node.js)**  
   Установка: `npm install chalk readline`  
   Запуск: `node tetris.js`

5. **Java**  
   Сборка: `javac Tetris.java`  
   Запуск: `java Tetris`

6. **C# (.NET Core)**  
   Запуск: `dotnet run`

7. **C++ (Linux)**  
   Сборка: `g++ -std=c++11 -o tetris tetris.cpp -lpthread`  
   Запуск: `./tetris`

8. **Kotlin (JVM)**  
   Сборка: `kotlinc Tetris.kt -include-runtime -d tetris.jar`  
   Запуск: `java -jar tetris.jar`

## Управление
- `←` / `A` – движение влево
- `→` / `D` – движение вправо
- `↑` / `W` – вращение
- `↓` / `S` – ускоренное падение
- `Space` – мгновенное падение (физика)
- `P` – пауза
- `Q` – выход
